# Legacy Flask application

This folder contains the previous Flask/MySQL implementation and its original templates and static files. It is retained as a migration reference and is not the active application or deployment target.

The active React/Next.js application is in the repository root. Start it with `npm ci` and `npm run dev`, and deploy the repository root as a Next.js project. See the root [README](../README.md) for environment variables, database setup, and deployment instructions.
